# Hermes 0.22.5 Standalone Alignment Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make the standalone K3s chart and custom-image workflow reproducibly select Hermes 0.22.5 and publish exact, opt-in source recipes for the compatible Paseo and Omnigent plugins.

**Architecture:** The Helm chart selects the public upstream image by immutable tag and digest; the custom Dockerfile consumes the same immutable base through a build argument. A repository-owned lock file plus staging script downloads exact plugin commits, verifies their archives and manifests, and writes only to an operator-selected staging directory. Installing, enabling, pairing, credentials, and profile migration remain explicit operator actions.

**Tech Stack:** Helm 3, Kubernetes YAML, OCI images, Bash, Python standard library, GitHub source archives.
